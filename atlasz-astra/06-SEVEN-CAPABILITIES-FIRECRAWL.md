## Firecrawl
Treat Firecrawl as a Tool Fabric/Research adapter, not as a replacement for the seven capabilities.
Desired capabilities when supported by the connected account/API: clean page extraction, structured extraction, crawl/batch URL processing, JavaScript-rendered page extraction, screenshots/evidence, caching where provider supports it.

Integrate through Tool Bridge so a real tested adapter is registered consistently in Universal Connector Layer + Tool Fabric + Executor Toolbox. Prefer use by the 5 SEARCH agents and Research workflows. Handle provider errors/rate limits; do not assume every site is scrapeable.
